## About the Project

I built this portfolio to showcase my work, share what I'm learning, and make it easier for recruiters and fellow developers to learn more about me.

The website has a dark theme with a blue and cyan accent palette, along with a responsive layout and dedicated sections for my experience, skills, and projects.

## Features

- Personal introduction and developer profile
- About me and technical skills
- Internship and work experience
- Projects with details and technology stacks
- Achievements and coding practice
- Resume download
- Contact and social media links
- Responsive layout for different screen sizes

## Tech Stack

- **Frontend:** React.js, JavaScript, HTML5, CSS3
- **Build Tool:** Vite
- **Version Control:** Git and GitHub
- **Deployment:** Netlify

## Run Locally

To run the project on your local machine:

1. Clone the repository:

   ```bash
   git clone https://github.com/KK15082005/Portfolio-KamaljeetKaur.git
   ```

2. Move into the project directory:

   ```bash
   cd Portfolio-KamaljeetKaur
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
